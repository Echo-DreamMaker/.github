Настоящее Соглашение создано исключительно с целью правовой защиты интеллектуального 
труда команды энтузиастов. Проекты Echo Dream Maker разрабатываются на безвозмездной

   звукового сопровождения и сценарных элементов.
3. Любые иные недобросовестные действия, нарушающие этику и принципы честной 
   разработки в open-source сообществе.

Участвуя в разработке и направляя свои изменения (Вклады) в репозитории проекта,
